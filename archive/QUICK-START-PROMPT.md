## Customization Instructions

Before pasting, update these sections:

### 1. Your Development Focus
Replace `[DESCRIBE YOUR WORK]` with something like:
- "Full-stack web development with React and Node.js"
- "PHP/Laravel development with Docker"
- "Python data science and machine learning"
- "DevOps and infrastructure automation"
- "Mobile app development with React Native"

### 2. Your Experience Level
Replace `[YOUR LEVEL]` with:
- "Beginner - new to Linux and development tools"
- "Intermediate - comfortable with terminal basics"
- "Advanced - experienced with system administration"
- "Expert - just want efficient setup guidance"

### 3. Existing Tools
Replace `[LIST ANY EXISTING TOOLS]` with what you already have:
- "Visual Studio Code, Docker, Git, Node.js via nvm"
- "Nothing - fresh Ubuntu installation"
- "Basic development tools, need to add containers and cloud tools"

## Usage Tips

1. **Copy the entire prompt** above (between the ``` marks)
2. **Customize the bracketed sections** for your specific needs
3. **Paste into your preferred AI** (Claude, ChatGPT, Gemini, etc.)
4. **Follow the interactive guidance** - ask questions freely!
5. **Take it step by step** - don't rush through installations

## Expected Response

The AI should respond with:
- System assessment commands to run
- Questions about your specific needs
- A customized installation plan
- Step-by-step guidance with explanations
- Testing procedures for each tool
